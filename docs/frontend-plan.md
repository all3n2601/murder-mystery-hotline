# Frontend plan (from the 2026-10-17 grilling)

Replaces the test bench (`apps/server/public/index.html`, moved to `/bench`). Overrides the frontend parts of [plan.md](plan.md) where they differ.

## Stack

- React 19 + Zustand for state and every piece of text or control (DOM overlays: captions, notebook, buttons, typed box, accusation, verdict).
- Plain PixiJS v8 behind one `<Stage>` component draws scenes only. Each scene is a class with `enter()`, `update(state)`, `exit()`; a small director subscribes to the store.
- `pixi-filters` (grain, glow, old-film, vignette) and GSAP (intro shots, cord swings).
- Every switchboard jack also has an invisible DOM button on top, so dialing works from the keyboard.
- SFX are synthesised with Web Audio (ring 440+480 Hz, rotary clicks, receiver thunks, busy crackle, rain and room tone from filtered noise). No Howler, no sound files.
- Fonts bundled via `@fontsource`: **Limelight** (titles, brass labels), **Special Elite** (notebook, evidence, case file), **Libre Baskerville** (captions, body).

## Look

Duotone noir: ink blue-black, warm amber lamps, brass hardware; red only for danger (nerves, accusation). Film grain and vignette everywhere.

Art: painted gouache, generated by the user from [cases/night-operator/art/PROMPTS.md](../cases/night-operator/art/PROMPTS.md):
- 4 suspects x 3 expressions (calm 0–3, uneasy 4–7, cracking 8–10 nerves), plus Mrs. Hale and a photo of Dot. 1024x1536 transparent PNG, waist-up, three-quarter view.
- 4 backdrops: exchange exterior at night, switchboard room, patch-cord close-up, call-log close-up.
- Code-drawn placeholders until the files exist. The interactive switchboard (jacks, lamps, cords) is always drawn in code.

Portrait motion (no lip-sync): breathing, a slight bob and brighter key light while speaking, a crossfade when a nerve threshold is crossed, jitter and lamp flicker at nerves 8+, snap to black on hang-up.

## Entry storyboard (~45 s, Esc / Skip at any point)

1. Title card: rain on glass, ringing phone, **"Pick up the receiver"**. The click creates the `AudioContext` and asks for the mic.
2. Exterior: MAdison Exchange, 2 a.m., one lit window, rain.
3. Interior push-in: switchboard lamps blinking, Dot's empty chair.
4. Close-up: the brass patch cord hanging loose.
5. Close-up: Dot's call log, lines highlighting as Mrs. Hale names them.
6. Push into the board, which dissolves into the playable switchboard. "Plug in, and start asking."

Mrs. Hale's narration is pre-rendered by a script using the same TTS (voice `anna`) into `cases/night-operator/intro/` (audio + word timings), so shots and captions line up exactly. Reduced-motion: fades only. A resumed game skips the intro; "Replay intro" lives in a menu; intro-seen is remembered in `localStorage` (wrapped in try/catch).

## Game screen

- Switchboard fills the screen: jacks with brass labels (name + line), lamps, sagging bezier patch cords.
- Call panel: portrait, VU-style nerves needle gauge, live captions.
- Notebook (right side; drawer on tablet): evidence cards, new clues stamped in, Mrs. Hale's hint cards. Hints stay automatic (no hint button).
- Top bar: punch-card question counter, **Accuse**.

## Controls

Hold **Space** or the on-screen button to talk (talking over a suspect interrupts). Typed box always visible, Enter sends, Space types while it's focused. **1–4** dial, **Esc** hangs up, **N** notebook, **A** accuse. Visible focus everywhere, captions on by default, `prefers-reduced-motion` respected.

## Endings

- Accuse: a manila case file. Pick one of four suspect cards, tick evidence, **File the charge**, confirm.
- Verdict: a *Herald* front page spins in (headline by outcome, stars, solution) while Mrs. Hale reads the ending. Play again.

## Diegetic states

- All lines busy: "ALL LINES BUSY" lamp blinks + crackle.
- Suspect hangs up: cord yanks out, lamp dies, dial tone.
- Mic denied: paper slip "No receiver: type your questions", talk disabled.
- Socket drop: "Line dropped… reconnecting" over static, auto-resume with `sessionId`.
- Server errors: shown as an operator's note, never raw codes.

## Serving

Fastify serves the Vite build at `/`; the test bench moves to `/bench` until launch. Vite dev proxies `/game` to the server.

## Build order (logic test-first with `mattpocock-skills:tdd`; visuals checked in the browser)

1. Game socket client + store (message reducer, resume).
2. Audio: mic worklet resampling to 16 kHz, playback that drops stale utterances, phone filter.
3. Game screen, playable by typing, then by voice.
4. Accusation + verdict.
5. Entry storyboard + narration pre-render.
6. SFX + polish.

## v2 (2026-10-18 grilling): story-first intro, portrait-first UI

- **Intro** is case data (`case.json` `intro.acts`, each suspect's `hook`, `intro.leads`): six acts (night, victim, scene, suspects, log, your job). Mrs. Hale's narration is rendered line by line over one TTS connection and spliced with the per-line pauses (`tools/render-narration.ts`, timing in `packages/engine/src/narration.ts`). Next ▸ (→) jumps an act, Esc skips. Warm close mix with a short room reverb, ambience ducking, and a synthesised underscore (`apps/web/src/audio/underscore.ts`). Four leads, one per suspect, close the intro and are pinned in the notebook.
- **The TTS performs no tags.** Sound cues are spelled out (`Haah…`, `Ha! Ha ha.`, `Heh heh.`); see `docs/reference/assemblyai/tts-markup.md`.
- **Layout**: the portrait takes most of the height; a brass rail with one card per suspect (portrait, lamp, nerves bar, clue count, *Not yet called* / *Hung up on you*); word-synced subtitles under the portrait.
- **Controls**: one stateful receiver button (`input/receiver.ts`: idle, ringing, ready, listening, thinking, speaking, type-only, out) with a live mic-level ring; Hang up beside it; "or type…" box. Keys: Space, 1–4, Esc, T, N (+Tab between tabs), A, ?.
- **Feedback**: thinking beat (lamp flicker, crackle, "… is thinking"), a questions-left ticket that turns amber then red, three first-game coach marks, an "Operator's card" help overlay.
- **Notebook** tabs: Clues (victim, leads, clues with portrait chips, evidence, Hale's notes), People, Transcript.
